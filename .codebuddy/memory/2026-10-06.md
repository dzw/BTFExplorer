## 外部工具“VSCode”路径改为运行时解析（不写死用户名）
- 用户原话“VSCode 应该调这里的 Code.exe”指**窗格右上角 ▾ 外部工具**（不是上下文右键菜单，也不是 Win+E 钩子）。此前误读成“钩子对 VSCode 放行”已撤销，Win+E 钩子恢复原样。
- 外部工具配置在 `tools.txt`（exe 同目录），格式 `名称|命令行`，`RunPaneTool` 用 `CreateProcess` 执行整条命令行（路径含空格必须加引号）。
- **不要**把用户名写死进源码：VSCode 路径用 `%VSCODE%` 占位符，运行时由 `ResolveVSCodePath()`（`src/UI/MainWindow.cpp`）解析——优先 App Paths 注册表 → 次选 `SHGetFolderPathW(CSIDL_LOCAL_APPDATA)+Programs\Microsoft VS Code\Code.exe` → 回退 `cmd /c code`。`RunPaneTool` 在 `%DIR%` 替换之外新增 `%VSCODE%` 替换（长度 8）。
- 默认 `kDefaults` 的 VSCode 行：`VSCode|%VSCODE% "%DIR%"`。tools.txt 不存在时首次启动落盘此默认；已存在则需改 tools.txt 本身才生效。

## 新增：不对称 3 窗格布局（Alt+4 / Alt+6）
- 需求：`Alt+4` = 一个窗格在左(整高) + 两个窗格在右(上下排)；`Alt+6` = 两个窗格在左(上下排) + 一个窗格在右(整高)。
- 冲突点：`Alt+1~4` 原本是“窗格数量”（Alt+4=4 个田字格）。按用户要求把 **Alt+4 改成了不对称布局**，4 窗格仍能经设置(panes=4) 或连点 `+` 达到。Alt+1/2/3 仍是数量。
- 实现（`src/UI/MainWindow.h` + `src/UI/MainWindow.cpp`）：
  - 新增状态 `asymMode_`(0/1/2)、`colSplitPermille_`(左右栏千分比，默认 500)、`colSplitX_`(列分隔条 x)、`rowSplitX0_/X1_`(行分隔条可命中的 x 范围)、`colSplitDragging_`。
  - `Layout()` n==3 分支：asym1/asym2 各自算 `colW=(gw-S)*colSplitPermille_/1000` 定左右栏，行分隔复用 `rowSplitY_`/`rowSplitPermille_`（限某栏的 x 范围由 `rowSplitX0_/X1_` 约束）。
  - 列分隔条可拖：在 `WM_LBUTTONDOWN/MOUSEMOVE/LBUTTONUP/SETCURSOR` 与 TabProc 的 `isSplitterHit` 里加列分隔命中（用 `colSplitX_`+全高范围，光标 `IDC_SIZEWE`）；行分隔已支持（光标 `IDC_SIZENS`）。
  - `SetAsymmetricTri(mode)`：`SetPaneCount(3)`（会清 asymMode_）→ 设 `asymMode_=mode` → Layout → SaveFavorites。
  - `SetPaneCount(n, keepAsym=false)` 新参数：非 keepAsym 时清 `asymMode_`（切数量布局回到对称）；`SetTriLayout` 也清 asym；`ApplySavedLayout` 用 `keepAsym=true` 保留重启时的不对称。
  - 持久化：favorites.txt 与会话文件均加 `asym=` 与 `col=`（存读都校验范围）。设置对话框“确定/应用”的 apply lambda 里捕获 `savedAsym`，应用后若仍是 3 窗格则还原 asym（设置里改不了不对称布局）。
- 验证：用应用日志(WriteAppLog → `%LOCALAPPDATA%\PagedExplorer\PagedExplorer.log`) 打临时 DBG，确认 `Alt+4→mode=1 / Alt+6→mode=2 / Alt+3→asym=0(重置对称)`。已删调试日志、重新编译通过。
- 注意（验证坑）：PowerShell 里 `GetClassNameW` 的 P/Invoke 只回传类名下标首个字符（marshaling 问题），所以跨进程按窗口矩形验证布局不可靠；**改 UI 布局后用 AppLog 打状态做权威验证**最稳。另：favorites.txt 的 `col=` 键与现有字段无冲突（确认过文件里只有 `col=500`）。
